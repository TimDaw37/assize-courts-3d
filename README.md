# Devizes Assize Courts – 3D Model

A before-and-after 3D model of the Assize Courts, Devizes, Wiltshire, which Wiltshire Museum is redeveloping. It is based on the Wiltshire planning applications <a href="https://development.wiltshire.gov.uk/pr3/s/detail/a0iQ300000Br6ybIAB?c__r=Arcus_BE_Public_Register" target="_blank" rel="noopener noreferrer">PL/2025/00246</a> and <a href="https://development.wiltshire.gov.uk/pr3/s/detail/a0iQ300000N2vg5IAB?c__r=Arcus_BE_Public_Register" target="_blank" rel="noopener noreferrer">PL/2026/04557</a>. This is an unofficial reconstruction by Tim Daw. It is not an official Wiltshire Museum, Wiltshire Council or architect's model.

**Live model:** <a href="https://timdaw37.github.io/assize-courts-3d/" target="_blank" rel="noopener noreferrer">https://timdaw37.github.io/assize-courts-3d/</a>

## How to help

This is an unofficial, amateur reconstruction. It is version 1, made without specialist tools, so it will have mistakes.

**Spotted an error?** If something is wrong, such as windows, heights or missing details, please report it through <a href="https://github.com/TimDaw37/assize-courts-3d/issues" target="_blank" rel="noopener noreferrer">GitHub Issues</a> or in the comments on my <a href="https://www.sarsen.org/" target="_blank" rel="noopener noreferrer">sarsen.org blog</a>.

**Most wanted:**
- Interior photos
- The cells
- Cornice and moulding details
- Historic photos

When you send images, please confirm that you own the rights to them or that they are out of copyright.

**Pull requests are welcome.** You are free to fork, reuse and share the model under the MIT licence. Please keep the data credits: EA LiDAR (OGL), OpenStreetMap (ODbL), Historic England and Ordnance Survey.

Please don't upload the planning PDFs or drawings to this repository.
